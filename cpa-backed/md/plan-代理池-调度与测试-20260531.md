# 代理池-调度与测试 Plan

## 用户原始需求

当前 `proxy-pool` 页面需要增强：

1. 添加代理时支持 `socks5`、`socks5h`、`http`、`https` 等形式。
2. 添加后可以对代理 IP 进行测试，查看代理是否可用。
3. 添加后的代理可以配置使用模式：
   - 随机使用
   - 固定同一 IP 连续使用，请求达到指定次数后切换到下一个 IP，例如每 100 次切换

## 技术方案设计

### 后端

1. 扩展代理池配置结构：
   - 保留现有 `proxy-pool` 数组
   - 增加代理池调度配置，至少包含：
     - `mode`: `random` / `rotate`
     - `requests-per-proxy`: 轮换模式下单个代理连续使用次数
2. 调整代理池选择逻辑：
   - `random`：维持现有随机挑选
   - `rotate`：在启用代理集合中按顺序轮换，达到阈值后切换到下一个
   - 仍然遵循现有优先级：`auth.ProxyURL` > 代理池/全局代理
3. 新增管理接口：
   - 获取/更新代理池调度配置
   - 测试单个代理可用性
4. 兼容现有请求日志展示：
   - 保持日志里已有的代理记录格式
   - 不影响现有请求日志页面与代理池日志页面

### 前端

1. 扩展 `ProxyPoolPage`：
   - 代理列表支持 `socks5` / `socks5h` / `http` / `https`
   - 每个代理增加“测试”按钮和测试状态展示
2. 新增调度设置区：
   - 模式切换：随机 / 顺序轮换
   - 轮换模式下可配置“每个代理连续使用请求次数”
3. 保持页面布局与现有风格一致，不引入新的页面结构
