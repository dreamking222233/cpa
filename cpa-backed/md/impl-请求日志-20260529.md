# Impl: 请求日志

## 任务概述

新增 OpenAI 请求日志页面 `/request-logs.html`，通过管理接口读取现有 request log 文件，展示每次请求的北京时间、模型、授权文件、输入 token、输出 token、缓存 token、推理 token、合计 token 和按 OpenAI 官方 API Pricing 估算的费用。

- `internal/api/handlers/management/request_log_summary_test.go`: 增加 usage 解析、去重、价格匹配和北京时间测试。

## 核心代码说明

- 接口 `GET /v0/management/openai-request-logs?limit=100` 扫描日志目录下的请求日志文件，排除 `main.log`，按修改时间倒序返回摘要。
- 日志解析支持 OpenAI Chat Completions 和 Responses 风格 usage：
  - `prompt_tokens` / `input_tokens`
  - `completion_tokens` / `output_tokens`
  - `prompt_tokens_details.cached_tokens` / `input_tokens_details.cached_tokens`
  - `completion_tokens_details.reasoning_tokens` / `output_tokens_details.reasoning_tokens`
  - `response.usage`
- 费用估算按 OpenAI 官方 API Pricing 的每 100 万 token 单价计算：
  - 非缓存输入 token 使用 input 单价。
  - 缓存输入 token 使用 cached input 单价。
  - 输出 token 使用 output 单价。
  - `gpt-5.4`、`gpt-5.4-pro`、`gpt-5.5`、`gpt-5.5-pro` 在输入超过 `270000` token 时应用 OpenAI 官方价格页标注的长上下文倍数。
- 对未知模型返回 `price_available=false`，页面显示“未匹配”，避免错误估价。
- 时间统一转换为 `Asia/Shanghai`，接口返回 `time_beijing`。
- 授权文件从 request log 的 `Auth: ... auth_id=...` 字段提取，并在页面作为“授权文件”展示；`type=api_key value=...` 会只提取 `api_key` 作为授权类型。

## 接口文档

- `GET /v0/management/openai-request-logs?limit=100`
  - 认证：同其他 management API，使用 `X-Management-Key` 或 `Authorization: Bearer <key>`。
  - 返回：
    - `logs`: 请求摘要列表
    - `totals`: token 和费用汇总
    - `pricing_source`: `https://openai.com/api/pricing/`
    - `pricing_checked`: `2026-05-29`
    - `timezone`: `Asia/Shanghai`
