# Plan: 代理池-批量添加

## 用户原始需求

代理 IP 添加页面当前只能逐个添加。需要支持批量导入/粘贴多行代理地址，并一次性加入代理池。

## 技术方案设计

- 在前端代理池页面增加批量添加输入区，支持每行一个代理 URL。
- 使用现有前端协议校验逻辑，仅接受 `socks5://`、`socks5h://`、`http://`、`https://`。
- 解析时去除空行，过滤当前代理池中已存在的 URL，并过滤同一次输入中的重复 URL。
- 生成默认名称，格式为 `批量代理 N`。
- 新增后端批量添加接口，一次性校验、服务端去重并持久化，避免前端逐条追加的部分成功问题。

## 实施步骤概要

1. 为后端管理 API 增加批量添加接口并注册路由。
2. 为前端代理池 API 增加批量添加方法。
3. 在代理池页面增加批量输入状态、解析函数和批量保存逻辑。
4. 在新增代理区域渲染批量粘贴控件、解析摘要和操作按钮。
5. 增加对应 SCSS 样式。
6. 运行前端 type-check/build 验证。
