# Impl: 代理池-批量添加

## 任务概述

为前端代理池页面增加批量添加能力，支持用户粘贴多行代理 URL 后一次性加入代理池。

## 核心代码说明

- 批量输入按行切分，契合“每行一个代理 URL”的导入格式。
- 支持协议仍限制为 `socks5://`、`socks5h://`、`http://`、`https://`。
- 自动过滤：
  - 空内容
  - 当前代理池中已存在的 URL
  - 本次粘贴中重复的 URL
  - 不支持协议或 URL 解析失败的内容
- 有效代理会追加到现有代理池，默认命名为 `批量代理 N`。
- 批量添加调用 `POST /proxy-pool/batch`，由后端统一过滤已存在或本批次重复的 URL，并一次保存。
- 如果当前页面有未保存的行内代理编辑或调度策略编辑，批量添加按钮会禁用并提示先保存或重置。
