# 代理池-调度与测试 Impl

## 任务概述

为 CPA 的代理池功能补齐以下能力：

1. 代理地址支持 `socks5`、`socks5h`、`http`、`https`
2. 管理端支持单代理可用性测试
3. 代理池支持两种调度模式：
   - `random`：随机使用
   - `rotate`：同一代理连续处理指定次数后切换到下一个代理
4. 前端 `ProxyPoolPage` 增加调度设置、代理测试和协议展示

## 核心代码说明

### 1. 代理池调度配置

新增 `ProxyPoolStrategy`，并在 `SDKConfig` 中暴露：

- `mode`
- `requests-per-proxy`

配置加载时统一做清洗：

- 空值或非法模式回退到 `random`
- `requests-per-proxy <= 0` 回退到默认值 `100`

### 2. 代理池选择逻辑

`internal/util/proxy.go` 从原来的“仅随机挑选”扩展为：

- `random`：维持随机行为
- `rotate`：基于内存游标按顺序轮换，并记录当前代理已使用次数

仍然保持原有优先级：

- `auth.ProxyURL`
- `proxy-pool`
- `proxy-url`

### 3. 管理接口

新增管理端接口：

- `GET /v0/management/proxy-pool/settings`
- `PUT /v0/management/proxy-pool/settings`
- `POST /v0/management/proxy-pool/test`

其中测试接口会：

1. 校验代理 URL
2. 通过该代理访问默认测试地址 `https://api.openai.com/v1/models`
3. 成功后尝试获取出口 IP
4. 返回成功状态、上游状态码、延迟、出口 IP 等信息

### 4. 前端代理池页面

`ProxyPoolPage` 新增：

- 调度策略卡片
- 顺序轮换时的“单代理连续请求次数”输入
- 每条代理的协议标签
- 每条代理的“测试代理”按钮
- 新增代理时的测试能力
- 测试结果展示：可用性、上游状态、延迟、出口 IP
