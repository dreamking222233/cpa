**阻断问题**
1. 价格估算对 `gpt-5.4` 长上下文请求会低估，且 `gpt-5.4-pro` 规则未覆盖。[request_log_summary.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary.go:73) 只内置了固定单价，[applyOpenAICost](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary.go:419) 也始终按固定公式计算；但 OpenAI 官方模型页明确写了 `gpt-5.4` / `gpt-5.4-pro` 在输入超过 `272K` 时，整次会话要按 `2x input`、`1.5x output` 计费。当前实现会把这类请求标成 `price_available=true`，但金额是错的。官方参考：[GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4)、[GPT-5.4 pro](https://developers.openai.com/api/docs/models/gpt-5.4-pro)。

2. `Auth:` 行对 API Key 凭证的字段解析是错的，会把 `auth_type` 污染成整段字符串。日志写入端会输出 `type=api_key value=...`，见 [logging_helpers.go](/Volumes/work_space/cpa/internal/runtime/executor/helps/logging_helpers.go:525)；解析端只按逗号切分，再直接取 `key=value`，见 [request_log_summary.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary.go:306)。结果 `AuthType` 会变成类似 `api_key value=sk-***`，而不是 `api_key`。这不符合“授权文件字段准确”的要求，而且现有测试只覆盖了 `type=oauth`，没有覆盖这个分支，见 [request_log_summary_test.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary_test.go:17)。

**其他结论**
OpenAI usage token 解析主路径看起来是对的：`usage`、`response.usage`、`cached_tokens`、`reasoning_tokens` 都覆盖了，[request_log_summary.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary.go:354) 的实现和当前日志格式基本对得上；北京时间转换也没看到明显问题，[request_log_summary.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary.go:296) 与测试 [request_log_summary_test.go](/Volumes/work_space/cpa/internal/api/handlers/management/request_log_summary_test.go:34) 是一致的。

路由权限方面，管理接口确实挂在管理中间件后面，[server.go](/Volumes/work_space/cpa/internal/api/server.go:558)；页面 `/request-logs.html` 和现有控制面板一样，只受 `DisableControlPanel` / `Home.Enabled` 限制，[server.go](/Volumes/work_space/cpa/internal/api/server.go:374) 与 [request_logs_page.go](/Volumes/work_space/cpa/internal/api/request_logs_page.go:187)。这部分没有看到新增越权问题。编译方面，我没看到这几处文件有明显语法错误，`git diff --check` 也干净；但当前环境没有 `go` 和 `gofmt`，无法实际跑编译或测试，所以“可编译”只能算未实证。
