# Impl: 前端管理中心改造

## 任务概述

拉取官方前端项目 `Cli-Proxy-API-Management-Center` 到当前工作区，并在该前端中补齐此前已经在后端侧增加的管理能力，确保可以通过前端完成以下操作：

1. 管理代理池，配置多个 SOCKS5 代理，并查看最近请求实际使用的代理。
2. 查看 OpenAI 请求日志，包括北京时间、模型、授权文件、输入/输出/缓存 token、费用估算，以及代理出口。
3. 在认证文件页面进行批量启用、批量禁用，并优先调用后端批量接口。

前端仓库最终放置路径为：

- `/Volumes/work_space/cpa/.frontend/Cli-Proxy-API-Management-Center`

这样可以避免 `go test ./...` 递归扫描前端 `node_modules` 干扰后端 Go 测试。

## 核心代码说明

### 1. 代理池页面

- 新增路由 `/proxy-pool`。
- 页面支持：
  - 查看当前代理池配置；
  - 新增代理；
  - 修改单个代理的名称、URL、启停状态；
  - 删除代理；
  - 查看最近 100 条请求日志中的代理使用链路。
- 请求日志展示使用 `GET /proxy-pool/request-logs`，直接看到 `request_id` 与代理链路的对应关系。
- 代理 URL 现在严格限制为 `socks5://` 或 `socks5h://`，前后端同时校验。

### 2. 请求日志页面

- 新增路由 `/request-logs`。
- 页面通过 `GET /openai-request-logs` 获取 OpenAI 请求摘要。
- 为满足“在请求日志页看到代理出口”的需求，页面额外调用 `GET /proxy-pool/request-logs`，按 `request_id` 将两份数据合并展示。
- 为避免补充数据失败拖垮页面，OpenAI 请求摘要和代理日志映射已改为独立降级加载。
- 页面展示字段包括：
  - 北京时间
  - 模型
  - 授权文件 / 授权标识
  - 代理出口
  - 输入 token
  - 输出 token
  - 缓存 token
  - 推理 token
  - 合计 token
  - 费用估算
  - 状态码
  - 请求 ID
  - 日志文件名

### 3. 认证文件批量启停

- `AuthFilesPage` 原本已经存在批量勾选和批量操作 UI。
- 本次改动将批量启停逻辑优先切换到新的后端接口：
  - `PATCH /auth-files/status/batch`
- 为兼容官方旧版本后端，如果该接口返回 `404/405/501`，前端会自动降级为逐个调用单文件状态更新接口。
